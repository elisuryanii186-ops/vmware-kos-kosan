===============================================
   CARA MENJALANKAN WEBSITE KOS-KOSAN
   Aplikasi Web dengan Docker & MySQL
===============================================

PRASYARAT:
==========
1. Docker Desktop sudah terinstall dan berjalan
2. Port 3000 dan 3306 tidak digunakan aplikasi lain
3. Minimal 2GB RAM tersedia


LANGKAH-LANGKAH:
================

1. BUKA COMMAND PROMPT / POWERSHELL
   - Tekan tombol Windows + R
   - Ketik: cmd
   - Tekan Enter

2. MASUK KE FOLDER PROJECT
   cd C:\Vmware_Kos-Kosan

3. JALANKAN DOCKER COMPOSE
   docker-compose up --build -d

   Tunggu proses build selesai (1-3 menit)

4. CEK STATUS CONTAINER
   docker-compose ps

   Pastikan muncul 2 container dengan status "running":
   - koskosan_web
   - koskosan_mysql

5. BUKA BROWSER
   - Website Publik: http://localhost:3000
   - Admin Panel: http://localhost:3000/admin/login

6. LOGIN ADMIN
   Username: admin
   Password: admin123


MENGHENTIKAN APLIKASI:
======================
docker-compose down


MENGHAPUS SEMUA DATA (RESET DATABASE):
======================================
docker-compose down -v
docker-compose up -d


MELIHAT LOG JIKA ADA MASALAH:
==============================
docker-compose logs -f


TROUBLESHOOTING:
================

MASALAH: "Port already in use" (Port sudah dipakai)
SOLUSI:
  1. Buka file docker-compose.yml
  2. Ubah port 3000 menjadi 8080:
     ports:
       - "8080:3000"
  3. Jalankan ulang: docker-compose up -d
  4. Akses di: http://localhost:8080

MASALAH: Container tidak mau start
SOLUSI:
  docker-compose down -v
  docker-compose up --build

MASALAH: Database connection error
SOLUSI:
  - Tunggu 10-15 detik setelah start (MySQL butuh waktu init)
  - Lihat logs: docker-compose logs mysql
  - Restart: docker-compose restart

INFORMASI TEKNIS:
=================

- Database: MySQL 8.0
- Frontend: Bootstrap 5
- Container: Docker + Docker Compose

Database Credentials:

- Port: 3306
- User: root
- Password: root
- Database: koskosan_db
